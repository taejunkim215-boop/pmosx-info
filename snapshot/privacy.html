개인정보처리방침

본 방침은 Apps Script Code Snapshot System의 코드 백업·운영 기록·경보 기능에 적용됩니다. 운영자와 문의처는 taejun.kim215@gmail.com입니다.

처리하는 정보와 목적

등록된 프로젝트의 이름·스크립트 ID·소스·매니페스트, 백업 파일 및 폴더 식별자, 해시, 파일 수, 변경 내역, 성공 시각, 오류 기록과 경보 수신 이메일을 처리합니다. 목적은 코드 변경 보존, 백업 상태 확인 및 장애 알림입니다. 소스에 개인정보나 비밀값이 포함돼 있으면 백업에도 포함될 수 있으므로 운영자는 소스의 민감정보를 관리해야 합니다.

저장 및 접근

코드 백업은 Google Drive, 프로젝트 관리·처리 내역은 Google Sheets, 전역 실행 시각은 Apps Script 속성에 저장합니다. 실행·오류 로그는 Google의 실행 기록 및 연결된 로깅 서비스에 남을 수 있습니다. 알림에는 프로젝트명·성공 시각·오류 내용 등이 포함될 수 있습니다. 저장 자료의 접근 권한은 운영자의 Google 계정 및 각 파일 공유 설정에 따릅니다.

보관·삭제

현재 백업 보존 설정은 180일입니다. 일요일 정리 실행 시 기준보다 오래된 파일을 휴지통으로 이동하며, 각 프로젝트 폴더의 최신 JSON·TXT 백업 쌍은 기간과 무관하게 보존합니다. JSON이 없는 폴더에서는 가장 최근 파일을 보존합니다. 휴지통 이동은 즉시 영구 삭제를 의미하지 않으며 Google Drive의 휴지통 정책이 적용됩니다. 관리 시트의 로그에는 별도 자동 만료가 구현돼 있지 않아 운영자가 관리합니다.

삭제 또는 사용 종료는 운영자에게 요청할 수 있습니다. 계정 접근 철회만으로 이미 저장된 백업·로그가 삭제되지는 않습니다.

제공·사용 제한

실행·저장·메일 기능에는 Google 서비스를 이용합니다. 공개 소개 페이지는 GitHub Pages로 제공하며 GitHub가 호스팅 과정에서 접속 정보를 처리할 수 있습니다. 백업 소스·실행 토큰을 이 공개 사이트나 공개 저장소에 게시하지 않습니다. Google에서 받은 데이터를 판매하거나 광고 또는 범용 AI 모델 학습에 사용하지 않습니다. 법적 의무를 제외하고 기능 수행에 불필요한 제3자 제공을 하지 않습니다.

Google API를 통해 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

접근 철회와 변경

Google 계정 연결 관리에서 접근을 철회할 수 있습니다. 철회 후에는 백업·감시 기능이 중단될 수 있습니다. 처리 방식이 바뀌면 본 방침을 갱신하고 새 권한이 필요하면 동의를 요청합니다.

Apps Script Code Snapshot System

운영자가 관리하는 Google Apps Script 프로젝트의 소스를 정기적으로 읽어 Google Drive에 백업하고, 백업 상태를 점검하는 개인 운영 도구입니다. 일반 이용자 가입 서비스는 제공하지 않습니다.

주요 기능

  • 관리 시트에 활성 상태로 등록한 스크립트의 소스 및 매니페스트 읽기
  • 정규화한 소스의 SHA-256 해시를 비교하고 변경 시 JSON·TXT 백업 생성
  • Google Sheets에 프로젝트별 성공 시각·해시·처리 결과 기록
  • 30시간 동안 성공 기록이 없는 항목을 점검하고 지정된 운영자에게 이메일 경보 발송
  • 설정된 보존 정책에 따른 오래된 백업 정리

이 도구는 대상 스크립트의 코드를 자동 수정하거나 복원하지 않습니다. 이 소개 사이트에는 로그인·백업 열람 기능이 없으며, 실제 백업은 운영자의 Google Drive에서 관리합니다.

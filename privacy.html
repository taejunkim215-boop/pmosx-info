개인정보처리방침

시행일: 2026년 10월 23일

본 방침은 개인 투자 자료 관리 도구 PMOS-X의 Google 계정 연결 및 공시·재무수치 수집 기능에 적용됩니다. 운영자 및 문의처는 taejun.kim215@gmail.com입니다.

1. 처리하는 정보

  • Google API 접근을 위한 OAuth 인증 정보(접근 토큰, 갱신 토큰 및 클라이언트 설정)
  • 자료 보관을 위한 Drive 폴더·파일 식별자, 이름, 크기, 체크섬, 접근 가능 여부 및 저장 자료
  • 공개 SEC 공시 원본, 기업 식별자, 재무수치 및 출처
  • 작업 시각, 처리 상태, 오류 유형 등 운영 기록

PMOS-X는 Google 계정 비밀번호를 직접 수집하지 않습니다. Google 인증 및 동의는 Google의 인증 화면에서 수행합니다.

2. 요청 권한과 목적

https://www.googleapis.com/auth/drive: Drive 파일의 조회·생성·수정·삭제가 가능한 넓은 권한입니다. 현재 수집 기능은 지정 보관 폴더의 탐색, 자료 업로드 및 읽기 검증에 사용합니다.

https://www.googleapis.com/auth/cloud-platform: 승인 계정의 IAM 권한 범위 안에서 Google Cloud 자원에 접근하는 권한입니다. 클라우드 운영 및 인증 구성에 사용합니다. 이 범위 자체가 추가 IAM 권한을 부여하지는 않습니다.

Google에서 받은 데이터는 승인된 자료 저장·조회·검증 및 해당 기능의 운영을 위해 사용합니다. 광고, 데이터 판매 또는 범용 AI·머신러닝 모델 학습에 사용하지 않습니다.

3. 저장 및 보호

공시 원본은 Google Drive에, 정리된 재무수치와 원본 메타데이터·처리 이력은 Neon PostgreSQL에 저장합니다. 무인 실행용 인증 정보는 Google Cloud Secret Manager에 보관하며 필요한 실행 계정에 접근 권한을 부여합니다. 인증 설정 과정에서 운영자의 Cloud Shell에도 인증 파일이 생성될 수 있습니다. 운영 로그는 Google Cloud Logging에 저장합니다. 인증 정보는 공개 웹페이지나 공개 저장소에 게시하지 않습니다.

4. 제공 및 서비스 이용

서비스 실행·저장·호스팅을 위해 Google Cloud, Google Drive, Neon 및 GitHub를 사용합니다. 각 제공자는 해당 서비스의 정책에 따라 정보를 처리할 수 있습니다. PMOS-X는 Google 사용자 데이터를 판매하거나 광고 사업자에게 제공하지 않습니다. 법적 의무에 따른 제공이 필요한 경우에는 관련 의무를 따릅니다.

5. 보관과 삭제

공시 자료와 재무수치는 개인 연구에 필요한 동안 보관합니다. 인증 정보는 계정 연결이 필요한 동안 유지하고 교체 또는 연결 종료 시 폐기 대상으로 관리합니다. 운영 로그와 백업은 각각의 저장소 보존 설정에 따르며 삭제 후에도 해당 보존 기간 동안 사본이 남을 수 있습니다.

삭제를 원하면 위 문의처로 요청할 수 있습니다. 계정 소유자는 Drive에 보관된 자료를 직접 삭제할 수도 있습니다. 데이터베이스 기록과 인증 정보의 삭제는 별도로 처리해야 합니다.

6. 접근 철회

Google 계정의 연결 관리에서 PMOS-X의 접근을 철회할 수 있습니다. 철회하면 이후 Google API 접근이 중단될 수 있지만 이미 보관한 자료가 자동 삭제되지는 않습니다. 자료 삭제는 별도로 요청하거나 수행해야 합니다.

7. 공개 소개 사이트

이 사이트에는 로그인 양식, 자체 분석 스크립트 또는 광고를 넣지 않습니다. GitHub Pages 호스팅 과정에서 GitHub가 IP 주소 등 접속 정보를 처리할 수 있으며 GitHub 개인정보처리방침이 적용됩니다.

8. Google 사용자 데이터 정책

PMOS-X의 Google API에서 받은 정보 사용 및 다른 앱으로의 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.

9. 변경 안내

처리 목적이나 저장 방식이 변경되면 이 페이지와 시행일을 갱신합니다. 새로운 권한이 필요한 경우 Google 동의 절차를 통해 요청합니다.
